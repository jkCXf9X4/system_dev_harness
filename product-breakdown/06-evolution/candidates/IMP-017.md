## Theme

PBS / Decomposition — Reorganize directory layout to reflect the functional-vs-physical boundary identified in IMP-016

## Evidence

- IMP-016 analysis of FBS-PBS boundary; current product-breakdown/ directory tree mixing functional concerns (intent, product commitments, use cases) and physical concerns (architecture, implementation)

## Current Pain Or Risk

Current directory layout does not visually separate functional breakdown artifacts from physical breakdown artifacts, making the FBS-PBS boundary invisible in the file system. This creates ambiguity for contributors about where new artifacts belong.

## Proposed Improvement

Analyze current directory structure and propose a reorganization that groups FBS artifacts (use cases, commitments, intent) separately from PBS artifacts (architecture, implementation, agents), with clear cross-reference paths between the two groups.

## Expected Benefit

File-system-level clarity on which artifacts belong to functional vs. physical decomposition; easier navigation for new contributors; visual reinforcement of the decomposition model.

## Risk And Blast Radius

Medium — file moves and renames break existing cross-references; requires coordinated README and traceability-map updates. Should be coordinated with IMP-016 completion.
