## Current Pain Or Risk

The reviewer can invoke memory helpers and lessons review, but the review protocol does not explicitly ask whether memory-derived assumptions were used, verified, rejected, or written. Memory can therefore affect task outcomes without a clear review trail.

## Proposed Improvement

Add a memory hygiene section to reviewer and reporter outputs when memory is relevant:

- memory entries retrieved
- memory-derived assumptions used
- entries revalidated against current files, commands, or decisions
- stale, conflicting, or rejected memory
- new memory entries written, updated, rejected, or deferred
- whether memory influenced approval, blocking, or waiver status

## Expected Benefit

Makes memory influence auditable and helps reviewers catch stale or over-generalized memory before it affects completion decisions.

## Risk And Blast Radius

Low to medium. Mostly prompt and review-output changes, but it can increase output verbosity. The section should be conditional on memory relevance.
