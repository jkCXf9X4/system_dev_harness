## Current Pain Or Risk

Workflow memory is explicit and versioned, but memory entries do not currently carry enough trust metadata to distinguish recently verified, environment-dependent, stale, broad, or low-confidence entries. A retrieved memory entry can therefore influence planning or review even when its target file, command, convention, or decision has drifted.

## Proposed Improvement

Extend workflow memory entries and memory-related agent outputs with lightweight trust fields:

- scope
- source or provenance
- last verified date or evidence reference
- confidence or applicability note
- revalidation trigger
- environment-dependent paths or commands, when relevant

Update memory retrieval and lessons review prompts to treat retrieved memory as a hypothesis when it affects task-critical action.

## Expected Benefit

Reduces stale-but-confident memory use and makes memory-derived assumptions easier for planner and reviewer stages to verify.

## Risk And Blast Radius

Medium. Affects memory file format, memory retrieval, memory curation, and lessons review prompts. Existing memory entries may need migration or default trust annotations.
