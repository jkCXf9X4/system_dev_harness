## Current Pain Or Risk

The project already distinguished lessons and patterns, but future memory curation could still blur factual memory, prevention rules, reusable procedures, and backlog work. Larger procedural guidance could become noisy if stored as always-retrieved memory.

## Proposed Improvement

Clarify the persistence destinations for different knowledge types:

- stable fact or decision pointer -> memory entry
- repeated failure and prevention check -> lesson
- reusable operating procedure -> pattern or skill-like artifact
- broad future work -> improvement candidate
- one-off task evidence -> task report or history, not memory

Add guidance for when a reusable procedure should become a pattern or future skill-like artifact rather than a memory note.

## Expected Benefit

Keeps durable memory concise and helps future agents decide where reusable knowledge belongs.

## Risk And Blast Radius

Low. This is mostly guidance and prompt clarification unless it introduces a new skill-like artifact format later.
