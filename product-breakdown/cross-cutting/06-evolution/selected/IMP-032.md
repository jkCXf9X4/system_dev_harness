## Current Pain or Risk

The orchestrator-systems-engineering agent (IMP-031) can currently produce only 3 of 7 SysML-adapted text artifacts from product-breakdown data. Four critical viewpoints are blocked:

1. **IBD (Interface specification tables) — INSUFFICIENT**: No formal interface contracts (ports, connectors, item flows, preconditions, postconditions) exist between agents. Handoffs are prose descriptions without schema definitions.
2. **Sequence Diagram (Interaction sequences) — INSUFFICIENT**: No message ordering, lifelines, or time-ordered exchanges documented. Cannot model "planner sends X to builder, builder responds Y to reviewer."
3. **State Machine (State/transition tables) — INSUFFICIENT**: Zero state documentation for any agent. No idle/active/blocked/waiting_for_input/completed states, triggers, guards, or effects.
4. **Parametric Diagram (Constraint blocks) — INSUFFICIENT**: Zero equations, performance bounds, resource constraints, or value bindings. Cannot quantitatively analyze revision loop caps, context window utilization, or concurrency bounds.

Additional risks:
- **Missing validation gate**: 30 verification criteria exist across 6 layers but zero criteria validate against actual user needs (ISO 15288 §6.4 gap)
- **Missing decision records**: PD (Product Decision), VD (Verification Decision), OD (Operational Decision) directories defined but contain zero decisions — rationale for verification strategy and deployment choices is undocumented
- **INCOSE/ISO copyright exposure**: 4 files contain direct ISO/IEC 15288 quoted process language (IMP-026, IMP-027, IMP-028, IMP-030)
- **IMP-031 lifecycle inconsistency**: File physically in `done/`, README says `selected/`, file metadata says "Selected" — three-way conflict
- **IMP prefix undefined in naming.md**: 28 IMP files use an undocumented naming prefix
- **evaluations/ directory declared but missing**: Referenced in 06-evolution/README.md but does not exist on disk
- **IMP-023 through IMP-025 numbering gap**: No artifacts exist for these IDs
- **03-implementation/ DECISIONS path mismatch**: README says `decisions/` subdirectory but IMD files at layer root

## Proposed Improvement

Consolidate findings into a single improvement candidate with 7 task-contract seeds for future delivery work:

1. **Task Seed 1 — Interface Contracts**: Produce IBD-adapted interface specification tables for all agent-to-agent handoffs (Payload schema, ports, preconditions, postconditions, error handling). Source data: architecture.md agent descriptions. Output: new `pbs/02-architecture/interface-contracts.md` or IB-00x decision records.

2. **Task Seed 2 — Agent State Machines**: Produce State/Transition tables for planner, builder, reviewer, and reflection agents (states, triggers, guards, effects). Output: new `pbs/02-architecture/agent-state-machines.md`.

3. **Task Seed 3 — Validation Gate Definition**: Add validation criteria section to centralized `acceptance-criteria.md` that addresses user-need satisfaction (ISO 15288 §6.4). Distinguish from existing verification criteria.

4. **Task Seed 4 — Missing Decision Records**: Generate PD-001 through PD-003 (product decisions for commitment rationale), VD-001 through VD-003 (verification strategy rationale), OD-001 through OD-003 (deployment/operation rationale) in their respective `decisions/` directories. Update `decision-log.md` index.

5. **Task Seed 5 — INCOSE/ISO Copyright Remediation**: Replace direct ISO/IEC 15288 quoted process language in IMP-026/027/028/030 with paraphrased descriptions. Keep section references ("per ISO 15288 §6.4") as citations. Add first-use SysML trademark attribution. Add attribution boilerplate to product-breakdown/README.md. Assess disposition of `SE_V5/INCOSE_SEHB5.txt`.

6. **Task Seed 6 — Structural Discrepancy Cleanup**: Fix IMP-031 lifecycle inconsistency (file location, README entry, metadata), add IMP prefix to naming.md, create missing evaluations/ directory, resolve 03-implementation/decisions/ path mismatch, document prompt-policy-extraction-tasks.md and undeveloped_improvements.md in 06-evolution/README.md.

7. **Task Seed 7 — Sequence Diagrams & Parametric Constraints**: Produce message-sequence tables for guarded delivery and candidate capture paths. Define parametric constraints for revision loop caps, context window utilization, and parallel-safe concurrency bounds.
