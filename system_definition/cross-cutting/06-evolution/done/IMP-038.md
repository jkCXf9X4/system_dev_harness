## Theme

Agent prompt de-duplication

## Evidence

- All 19 agent prompts under `.opencode/agents/` contain rules duplicated from canonical workflow policy files under `.opencode/dev_harness/workflow/`
- KM-010 documents this pattern: "Agents may duplicate behavioral rules, constraints, or guardrails that already exist in canonical workflow reference files"
- Planner prompt (~14KB): ~30-40% of content duplicates `control-policy.md` (Route Selection, Clarification Gate, Plan Draft Approval, ID-Based Handoff) and `adaptive-risk-triggers.md` (Planner Triggers)
- Builder prompt (~5KB): duplicates plan-loading rules from `plan-summary-schema.md`, candidate-capture rules from `candidate-capture.md`, interface-consistency rules from `interface-consistency.md`
- Reviewer prompt (~6KB): duplicates plan-file-verification rules from `plan-summary-schema.md`, helper selection from `adaptive-risk-triggers.md`, parallel-execution from `parallel-helper-execution.md`
- Total agent prompt sum: ~60KB. Estimated 30-50% is duplicated from policy files.

## Current Pain Or Risk

Agent prompts are 30-50% larger than necessary. Each agent invocation loads duplicated content that already exists in canonical policy files. This wastes tokens on every single agent invocation across every workflow run. For the planner alone (~50KB static context), an estimated 5-7KB is duplicated content. Across all agents, an estimated 15-25KB of static context is duplicated per full workflow run. Duplication also creates maintenance risk: when a canonical rule is updated, the copies in agent prompts become stale and contradictory.

## Proposed Improvement

Audit all 19 agent prompts and strip any rule, constraint, or guardrail that already exists in a canonical workflow reference file under `.opencode/dev_harness/workflow/`. Replace with cross-references. Keep only role-specific instructions: what the agent does, its unique responsibilities, its output format. Apply KM-010's prevention rule systematically.

## Expected Benefit

30-50% reduction in agent prompt size. For the planner, ~5-7KB saved per invocation. Across all agents in a full workflow run, estimated savings of 15-25KB of static context. Reduced maintenance burden from eliminating duplicate rules.

## Risk And Blast Radius

Low — removing duplicated rules cannot change behavior if the canonical source is still loaded by the agent. Risk is that a rule is removed from an agent prompt but the canonical reference is not loaded by that agent. Mitigation: verify each agent still loads the canonical file that contains the removed rule. Cross-reference changes only — no logic, permission, or boundary changes.
