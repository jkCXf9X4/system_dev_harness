## Current Pain Or Risk

Workflow profile descriptions in `planner-triggers.md` may not fully align with actual frontmatter YAML structure across orchestrator-* agents. There is potential drift between documented profile expectations and agent configuration reality. This creates a trust gap: developers and agents reading the documentation cannot be confident it reflects the actual agent configuration, which undermines the value of the workflow profile documentation as a reliable reference.

## Proposed Improvement

Audit `planner-triggers.md` profile descriptions against all agent frontmatter files; reconcile any gaps found. The audit should cross-reference each profile section in the documentation against the corresponding orchestrator-* agent's frontmatter YAML, identify discrepancies, and produce a reconciliation plan.

## Expected Benefit

Consistent, trustworthy documentation of workflow profiles. Agents and developers can rely on `planner-triggers.md` as an accurate reflection of how profiles map to agent configurations.

## Risk And Blast Radius

Low — documentation-only audit; no behavioral change. The blast radius is limited to `planner-triggers.md` and potentially agent frontmatter comments. No runtime behavior, agent logic, or workflow control flow is affected.
