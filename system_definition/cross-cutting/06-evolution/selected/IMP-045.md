## Current Pain Or Risk

The C05 invariant is the parametric constraint that enforces the guarded chain ordering. It is now architecturally invalid — the system's parametric model disagrees with the actual workflow. This creates a documentation gap where the authoritative architecture reference contradicts runtime behavior. Future agents referencing `sequence-parametric.md` for stage ordering will encounter a stale, incorrect chain that omits validation, potentially causing routing confusion.

## Proposed Improvement

Update `sequence-parametric.md` to insert validation messages (Seq 12a-12c) between current Seq 12 and 13, and update C05 to `planner -> builder -> validation -> reviewer -> reflection -> reporter`. This makes the parametric model consistent with the operational workflow after IMP-026.

## Expected Benefit

- Architectural documentation becomes consistent with runtime workflow.
- C05 Stage Order Invariant is restored as an accurate parametric constraint.
- Eliminates confusion risk for future agents or operators inspecting the sequence diagram.

## Risk And Blast Radius

Low — single documentation file (`sequence-parametric.md`), no code or agent changes. The C05 invariant text and sequence diagram are the only affected sections. The guarded delivery path section (lines 15-42) also needs a parallel update to include validation. No runtime or behavioral impact.
