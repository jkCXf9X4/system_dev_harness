## Theme

Cross-stage token efficiency

## Evidence

- `stage-output-schema.md` — defines common output fields but has no compression or summarization mechanism for helper outputs
- Planner work orders include inline helper outputs (discovery file lists, contract requirement specs, architecture constraints) that flow verbatim through builder → reviewer → reflection → reporter
- Typical discovery output: 2KB+ of file paths and search results
- Typical contract output: 3KB+ of requirement specifications
- Typical architecture output: 2KB+ of guardrails and constraints
- A task with 3 helpers generating 2KB each = 6KB × 5 stages = 30KB of repeated helper output content through the chain

## Current Pain Or Risk

The ID-based handoff (plan file on disk) partially mitigates this, but helper outputs are still included inline in the planner's work order. Builder loads them from the plan file, but reviewer and downstream stages see them again through the accumulated conversation. Raw search results, full file lists, and verbose requirement descriptions are passed through stages that don't need that detail — only the decisions, constraints, and action items matter downstream.

## Proposed Improvement

Add a compression protocol to `stage-output-schema.md`: helpers return a compact summary (≤500 tokens) plus a `full_output_path` reference to a file on disk. Parent stages load the full output only when needed. The planner synthesizes helper outputs into the work order rather than passing raw output — keeping only decisions, constraints, and action items, not raw search results or full analysis.

## Expected Benefit

60-80% reduction in cross-stage helper output token usage. For a typical task with 3 helpers, estimated savings of 10-20KB across the full chain.

## Risk And Blast Radius

Low-Medium — requires changes to `stage-output-schema.md` and all helper output formats. Risk that compressed summaries lose important detail. Mitigation: keep full output on disk, make compression optional per risk profile (high_assurance keeps full output, standard/lightweight uses compression).

## Task Contract Seed

Add `compressed_output` and `full_output_path` fields to `stage-output-schema.md`. Add compression guidelines: max 500 tokens, must include all decisions and constraints, may omit raw search results. Update planner prompt to synthesize rather than relay helper outputs.

## Out Of Scope

Do not change what helpers produce — only how their output is relayed. Do not remove evidence requirements.
