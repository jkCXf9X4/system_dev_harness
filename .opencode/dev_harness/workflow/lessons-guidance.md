# Lessons Guidance

Use this guidance when a task needs lesson memory, prevention rules, or lesson-based review.

## Shared Lessons Rules

- Identify only the lessons that matter for the caller-provided task context.
- Turn relevant lessons into prevention rules or review checks that the caller can act on immediately.
- Keep the list small and task-specific.
- When evidence contradicts a lesson entry, call that out explicitly and treat the lesson as needing revalidation.
- Return new lesson candidates only when the evidence reveals a repeatable failure pattern.

## Context Expectations

- The caller must provide the task context, builder evidence, or review evidence that makes a lesson relevant.
- Do not treat lesson memory as a substitute for the caller's evidence bundle.
