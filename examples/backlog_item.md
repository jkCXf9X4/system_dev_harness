# Task: Add Contract-Driven External Agent Handoff

The harness currently produces a general agile delivery brief. Adjust it so it creates a guarded implementation packet that can be handed to an external coding agent.

The task should prevent coding agents from:

- implementing only a plausible subset
- ignoring requirements or architecture constraints
- losing track of the original task
- repeating known mistakes

The result should include:

- a requirement contract
- architecture guardrails
- known mistake checks
- an implementation packet
- a paste-ready external agent handoff
- reviewer council findings
- a completion decision
- a final control report

The harness should still run from the command line and should not edit code directly.
