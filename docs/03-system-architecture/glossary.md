# Glossary

## Advisory Mode

The harness generates analysis, plans, reviews, and checklists but does not modify code or external systems.

## Agile AI Harness

A governed workflow that uses AI agents to support agile discovery, delivery, validation, and improvement.

## Artifact

A markdown output produced by one harness node, such as a value review or QA plan.

## Checkpoint

A persisted graph state snapshot created by LangGraph at workflow step boundaries.

## Delivery Slice

The smallest useful unit of delivery that can produce stakeholder feedback or validated learning.

## Human Approval Gate

A point where a person inspects and approves or edits the state before the workflow continues.

## Learning Value

Value created by reducing uncertainty, validating assumptions, or enabling better future decisions.

## Non-Feature Value

Value from work that does not directly ship a user-facing feature, such as maintainability, reliability, security, observability, or risk reduction.

## Role-Based Agent

An AI node with a specific responsibility and artifact contract, such as Product Value Agent or QA Agent.
